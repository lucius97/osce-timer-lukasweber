# OSCE Timer

Synchronised multi-station exam timer. Controller + observer roles, real-time sync via Firebase.

## Setup

1. Copy `config.js.example` → `config.js`
2. Fill in your Firebase project credentials in `config.js`
3. Open `osce-timer.html` in a browser — or host via GitHub Pages

`config.js` is in `.gitignore` and will never be committed.

## Files

| File | Purpose |
|---|---|
| `osce-timer.html` | The app — open this in any browser |
| `config.js` | Your Firebase credentials (not committed to git) |
| `.gitignore` | Keeps `config.js` off GitHub |
